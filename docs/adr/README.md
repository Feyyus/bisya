# Architecture Decision Records

One file per decision, numbered sequentially, never renumbered or deleted — if a decision changes, write a new ADR that supersedes the old one and mark the old one's status accordingly.

Format: Status / Context / Decision / Consequences (Nygard-style — see any file here for the shape).
